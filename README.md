<h1 align="center">RelyLess</h1>

<p align="center">少一点依赖，多一点直接读懂。</p>

RelyLess 是一个面向英语阅读的 Chrome / Edge 扩展。它保留网页上的真实英文，只在需要时给出稀疏的简明英文提示、局部中文说明和可选的阅读解构。

它的默认目标不是把整页替换成中文：自动辅助只面向能可靠识别的主要阅读区域，普通页面导航、控件和无关内容不会被自动翻译。导航链接可通过查词键单击或右键菜单单独请求译文。本页双语翻译需要单独确认，只随阅读位置处理附近正文，保留英文并原位插入译文；结果仍取决于所选模型，可能超时、失败或不完整。

> 当前版本：`v0.4.1`。通过 GitHub Releases 提供，尚未发布到 Chrome Web Store 或 Microsoft Edge Add-ons。

## 产品理念

读英文时，我们常常需要一点帮助，但不一定需要另一篇中文文章。RelyLess 希望帮助你继续读原文，而不是让译文接管阅读。

**RelyLess，意味着更少依赖。** 我们想做的是阅读中的临时支撑：卡住时托一把，读得下去时少打扰。目标不是让你看更多提示，而是让你逐渐不再需要那么多提示。

- **英文是主体，提示是配角。** 保留原文和阅读节奏，优先用简明英文解释当前语境中的难点，不把默认体验变成满屏注释或中英对照。
- **中文是退路，不是禁区。** 英文解释仍不够时，可以主动请求局部中文说明。先读懂眼前的内容，比坚持某种“正确”的学习方式更重要；本页双语翻译仍需单独确认。
- **少打扰，也保留选择。** 支持可以是提示、仅标记或安静不展示，也可以由你主动求助。不把每次阅读变成背词、打卡或掌握度考试。
- **帮助有边界，数据也一样。** 本地优先不等于完全离线；模型请求的数据去向应当说清楚，阅读记录、摘要与远程个性化分析由你明确开启。具体范围见[数据与隐私](#数据与隐私)。

我们更看重：你是否读完了真正想读的内容，以及下一次能否少求助一点。这是产品的设计方向，不是对学习效果的保证。

安装后可在 **设置 → 使用说明** 按阅读场景查看指南：词义不确定时用注释，长句读不顺时用阅读解构，提示太多时调整帮助，需要大意时请求局部翻译。标记与词注、渐退与恢复、模型请求及数据隐私的说明融入对应场景；查词按键会跟随当前设置。

网页中的查词卡片、阅读解构卡片、翻译操作条和状态反馈均带有 RelyLess 来源标识；原文标记、顶部词注和结构下划线不添加 Logo，也不新增常驻悬浮入口。

## 主要能力

- 保留英文原文，在词、短语和句子附近提供有限提示；需要时可主动请求局部中文说明并继续追问。
- 阅读解构标出主谓宾和修饰结构；选段翻译、本页双语翻译与干净原文复制分别按需触发。
- **专注阅读**：在弹窗主动进入当前正文快照，临时隔离网页干扰而保留原文；无需配置模型，也不会仅因进入而请求模型。即使本页辅助未开启，仍可按住 D 单击正文英文词主动求助；自动提示不会因此开启。顶部可单独确认「翻译本页」，仅按阅读位置翻译快照正文；退出恢复原网页。原页已有双语译文时会暂停后保留，退出可继续处理。原页和视图共用词档案与会话帮助缓存；同词同语境的已有结果可复用，语境或解释语言变化时会重新确认，进入视图不会把旧释义自动贴满正文。正文无法可靠识别时拒绝进入。
- 「我已认识」会撤下现有提示；到期词可在当前阅读页面用轻量复习面板快速回顾。
- 可配置提示密度、查词方式、显示样式、领域识别、固定术语和网站规则。
- 阅读记录、摘要与远程个性化分析需明确开启；本地求助词档案默认开启，可关闭、导出或清理。“仅在需要时”不扫描或记录被动阅读活动；即使本页已开启阅读解构，也不自动扫描句子。选中完整单句后点“解构所选”、主动查词与“减少提示”仍可用。
- 设置中的模型用量优先显示服务商上报的 token；≈ 是粗略估计，不是服务模型的精确分词或账单。估计可使用已预热的本机 MiniLM 分词器，较长内容改按完整载荷字符数计算；不保存请求正文。
- 模型服务可选择自备 API，或通过本机连接器使用官方 CLI 访问 ChatGPT、Grok、Google（Antigravity）订阅权益。
- 设置中的“模型用量”按服务与模型显示本机聚合的请求、错误和 token 计数；缺失的 token 数单独显示估算值，不等同于服务商账单。可单独清空，清空失败会提示重试；无痕请求不计入本机统计。详见 [隐私政策](PRIVACY.md)。
- 每个 API 服务可保存最多 8 个密钥，按权重轮询并在认证、限流或临时故障时自动切换；可逐项检查密钥。
- 可选的 Jev 模型路由只判断明确开启的高价值请求；判卷或升级服务不可用时回落当前服务。
- 内置本地领域识别模型，随扩展提供，不需要首次运行时另行下载。设置页的“领域测试”可在识别不确定时显示候选领域；网站规则仍由你手动设置。
- 简短查词优先交给本机 Gemini Nano（成功时不联网、不计费）；本机调用失败或返回无效内容时，和其余请求一样回落已配置的就绪服务，远端结果不会标为本机生成。
- 释义与本页译文默认仅在本次会话缓存；跨会话缓存需在数据与隐私中单独开启；可为服务配置故障转移链，也可设月度 token 预算（超限需二次确认）。
- 追问在 API 服务与升级后的 ChatGPT 订阅连接器上都支持多轮上下文。
- 可按 `]` / `[` 在标记词间键盘导航（默认关闭，在设置中开启）。

模型输出不是事实保证。网络、额度、权限、模型兼容性、内容安全策略和响应格式都可能导致请求失败；失败时不应把未确认结果当作可靠翻译。

## 快速开始

1. 打开 **设置 → 模型服务**，选择订阅连接器或自备 API，完成登录或保存后先执行一次连接检查。
2. 打开英文文章，点击扩展图标，再点 **开启本页**。只想自己决定何时求助，可在 **阅读偏好** 选择「只在主动求助时」。
   只想临时清爽地读原文，可直接点击弹窗的 **进入专注阅读**，无需先开启本页辅助或配置模型。按住 D 单击正文英文词可主动求助，未连接模型时会明确报错；这不会开启被动分析。原页已有双语译文时会暂停并保留，退出后恢复原页结果。在视图顶部可以单独确认「翻译本页」，或调整字号、栏宽、行距和明暗主题；按 Escape 或点击 **退出专注阅读** 返回原网页。无法可靠识别正文时会提示并留在原页；媒体、未加载图片仍请回原页查看。
3. 遇到生词：按住当前查词键（默认 `D`）并单击可见英文词语；正文、其他链接、侧栏和控件文字会打开解释卡片，支持局部中文说明、本句翻译和追问。导航链接上的该操作直接翻译整条标签，不显示词义卡片；再次操作可撤下译文。普通点击链接或按钮仍执行原操作。输入区、编辑内容、隐藏文字及代码块不处理。
4. 词都认识但句子读不顺：在弹窗开启 **阅读解构**，先看主谓宾，再展开修饰部分。
5. 只翻译眼前内容：选中正文后点击「翻译所选」；选中单词时可点「翻译本段」。导航链接按住查词键单击其中一个英文词，或右键选「RelyLess：翻译导航链接文字」，中文会直接显示在原标签旁，不弹出卡片；原文和链接保持不变。
6. 复制不带词注和译文的原文：选中段落里的文字，右键选「RelyLess：复制选中段落的原文」。
7. 需要整页辅助：点弹窗中的 **翻译本页**，或在专注阅读顶部点 **翻译本页**，阅读数据与费用提示后确认。

浏览器没有预设扩展快捷键；快捷键页会列出浏览器自带的「激活该扩展程序」和 RelyLess 的「开启或暂停当前网页」两个未设置入口。需要时可在 `chrome://extensions/shortcuts` 或 `edge://extensions/shortcuts` 自行绑定不冲突的组合。Mac 的 Option（⌥）在浏览器设置里也称 Alt。设置里的标记导航 `[` / `]` 默认关闭。详细场景见扩展内 **设置 → 使用说明**。

### 使用本页双语翻译

工具栏弹窗的 **本页双语翻译 → 翻译本页** 会先显示数据与费用确认，不会因打开弹窗就发起模型请求。

进度按正文单元计数，区分已译、待阅读、失败和跳过。只处理视口附近正文，不后台预译整篇；无法安全原位插入的特殊布局保留英文并报告跳过。失败段落只在手动重试时重新请求，已成功部分不会重发。停止保留已有译文，继续需要再次确认；返回英文只移除扩展插入物，不回滚站点更新。已发出的请求可能继续计费。

使用 ChatGPT 订阅连接器时，扩展与连接器须一起更新，并重新运行连接器安装程序；本次全文协议不兼容旧连接器。

## 从 Release 安装

要求 Chrome 或 Edge **116 及以上版本**。

1. 从 GitHub Releases 下载 `relyless-0.4.1.zip`。
2. 解压后会得到 `relyless-0.4.1/`，其中包含：
   - `extension/`
   - `connector/`
   - `README.md`
   - `LICENSE`
   - `NOTICE.txt`
3. 打开扩展管理页：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
4. 开启“开发者模式”。
5. 选择“加载已解压的扩展”，指向解压后的 **`extension/` 目录**。

Release 包已经包含运行所需文件和本地模型，不包含源码开发依赖；使用 API 模式时无需安装 npm 依赖，也无需构建。

请把解压后的目录放在一个长期不变的位置。未打包扩展的 ID 与目录位置相关：移动目录可能改变扩展 ID，并使本机连接器失效。升级时应保持现有目录路径不变，在原位置替换版本内容，然后在扩展管理页重新加载。

## 配置模型服务

在扩展设置的“模型服务”中选择一种服务来源。

### 自备 API

填写服务商、模型 ID、必要的 Base URL，以及一个或多个 API Key；多个密钥按一行一个填写，保存后可用「逐项检查密钥」分别验证。RelyLess 会按权重轮询，并在认证、配额、限流或临时网络故障时切换可用密钥。API Key 和服务配置保存在浏览器扩展的本机存储中；调用时，当前使用的密钥和请求内容会直接发送给你配置的服务端点，错误与诊断会对已保存密钥脱敏。

API 的账户、费用、额度、地区可用性、数据处理条款和所需权限均由你与服务商负责。RelyLess 不附带 API 额度，也不承诺第三方服务免费、持续可用或不留存数据。

在 macOS / Linux / Windows 上支持 ChatGPT、Grok 及 Google（Antigravity）订阅连接器。自备 API 在所有受支持的浏览器平台上均可直接使用。

### 可选模型路由

模型路由默认关闭。开启后，RelyLess 使用「领域识别」里的 Requesty / Jev 配置，为你勾选的主动求助、选段或整页翻译、追问等请求判断是否升级到指定服务。普通自动词注不会额外判卷，阅读解构也默认不参与。

判卷接收的是有界请求摘要，不是整页内容；判断按操作、内容和设置版本在本机缓存。判卷失败、升级服务未配置或订阅未登录时，请求回落到当前服务。请同时考虑 Jev 请求和升级服务可能产生的费用。

### 订阅连接器

RelyLess 支持通过 Native Messaging 本机连接器对接官方 CLI，直接利用你的现有 AI 订阅权益。

#### 1. ChatGPT 订阅连接器（macOS / Linux / Windows）

连接器要求：
- macOS、Linux 或 Windows；
- Node.js 20 或更新版本；
- 官方 [OpenAI Codex CLI](https://github.com/openai/codex)，且 `codex --version` 可正常运行（Windows 上 `codex.cmd` 亦可，安装程序会自动经 cmd 包装）。

安装 Codex CLI：
```sh
npm install -g @openai/codex
```

在解压包或项目根目录运行安装程序。必须把下面的占位符换成扩展管理页显示的、**你自己的实际扩展 ID**：
```sh
node connector/install.mjs --extension-id <YOUR_ACTUAL_EXTENSION_ID>
```

#### 2. Grok 订阅连接器（macOS / Linux / Windows）

连接器要求：
- macOS、Linux 或 Windows；
- Node.js 20 或更新版本；
- 官方 Grok CLI（`@xai-official/grok`），且 `grok --version` 可正常运行；
- 拥有 SuperGrok 或 X Premium+ 订阅，并已通过 CLI 登录（`grok auth login`）。

安装 Grok CLI：
```sh
npm install -g @xai-official/grok
```

运行安装程序（指定 `--backend grok`）：
```sh
node connector/install.mjs --extension-id <YOUR_ACTUAL_EXTENSION_ID> --backend grok
```

#### 3. Google 订阅连接器（macOS / Linux / Windows）

连接器要求：
- macOS、Linux 或 Windows；
- Node.js 20 或更新版本；
- Google Antigravity CLI（`agy`），且 `agy --version` 可正常运行；
- 拥有 Google AI Pro 或 Ultra 订阅，并已通过 CLI 完成账户登录。

运行安装程序（指定 `--backend antigravity`）：
```sh
node connector/install.mjs --extension-id <YOUR_ACTUAL_EXTENSION_ID> --backend antigravity
```

#### 连接器通用说明

不要复制他人的扩展 ID，也不要把任何特定电脑上的 ID 写进脚本或公开配置。默认会为 Chrome 和 Edge 注册连接器；可用 `--browser chrome`、`--browser edge` 或逗号分隔的列表限制目标浏览器。安装后重新加载扩展，在“模型服务”中选择对应订阅并点击“刷新账户与模型”，并按需完成登录。

移动扩展目录后，浏览器可能生成新 ID；此时必须使用新的实际 ID 重新安装连接器。更稳妥的升级方式是始终保留原目录位置。订阅是否包含可用模型和调用额度由各服务商账户状态决定，订阅不等于无限或保证可用。

## 数据与隐私

“本地优先”不等于“所有处理都离线”。本地领域识别和本机记录不需要把整页上传到 RelyLess 自有服务器；项目本身不提供中转云服务。但使用 API 或 ChatGPT 订阅连接器时，完成任务所需的内容会发送给你选择的模型服务商：

- 普通辅助会发送目标词句及适用的页面标题、章节信息和上下文；自动预备的文章上下文最多 12,000 字符，较短文章可能整体包含在内。请求同时包含任务指令与结构化输出约束。
- 选择远程领域识别时，会发送标题和经过长度限制的正文样本；默认本地领域识别不需要该远程请求。
- 明确开启“模型路由”后，目标词句或上下文等最多 2,000 字符的请求摘要会先发送到设置的 Jev 接口（默认地址为 Requesty），再由原服务或升级服务处理；普通窗口只在本机缓存摘要对应的判断结果，无痕窗口不留此缓存。
- 主动翻译选段时，会发送所选片段及有限上下文。视频字幕支持暂时隐藏，不挂载播放器入口；已有视频偏好保留。
- 本页双语翻译仅在确认后发送附近正文及有限上下文：标题、所在章节各最多 160 字符，相邻正文前后各最多 400 字符。每批最多四项、源文本合计最多 4,000 字符，源文本加上下文最多 12,000 字符；不读取输入框、隐藏正文或视频字幕。不会因此额外生成摘要、写入全文阅读事件或个人词档案；成功译文可进入默认会话缓存，本页译文另有五分钟、最多 256 项的后台内存缓存。
- 如果明确开启阅读摘要，会发送长度受限的阅读样本；如果进一步开启个性化分析，会发送近 30 天内有限的查询、例句、摘要和客观活动统计证据。
- 主动追问的问答、有限上下文、页面标题和不含查询参数或片段的页面地址会在本机保留最多 30 天，供继续追问；无痕窗口不保存追问历史。

请求载荷不主动包含页面网址，但服务商仍可获得正常网络请求元数据，并可能按照其自身条款记录请求、账户和内容。RelyLess 无法承诺第三方或自建 API 服务端不留存数据；请在使用前检查所选服务商的隐私与保留政策。

扩展设置中的边界如下：

- “记住求助词与支持偏好”默认开启；关闭后，不再读取或更新个人词档案；原有档案会保留，除非在“数据与隐私”中清理。
- “阅读记录”需要明确开启并添加允许的网站；关闭采集不会自动删除已有记录。
- 阅读摘要和个性化分析是阅读记录之上的独立开关，没有授权时不会运行。
- 预备解释和有限上下文缓存只保留在当前浏览器会话；个人词档案不保存原句、标题或来源网址。 简短词义帮助、选段与本页译文默认也只在会话中缓存；在“数据与隐私”明确开启后才跨会话保留最多 30 天（词义最多 500 条、译文最多 1,500 条）。关闭开关会删除持久缓存，也可单独清空；缓存值包含模型生成文本，不应当视为匿名数据。
- 无痕页面不采集阅读记录、词汇记忆、复习反馈或诊断事件，也不读取普通窗口的个人词档案；主动模型请求仍会发送到所选服务。可在“数据与隐私”中导出或清理本机数据。

## 从源码开发

源码仓库包含扩展、本机连接器、测试、构建工具以及随扩展分发的本地模型运行库，检出体积约 46 MB。`package.json` 保持 `private: true` 是为了防止误发布到 npm，不影响 GitHub 源码公开。

要求 Node.js **20.11 或更新版本**，以及 [Bun](https://bun.sh/)（用于测试与演示服务器）。

```sh
git clone https://github.com/rockythink/relyless.git
cd relyless
npm ci
npm run check
```

依赖锁文件使用 `overrides` 固定已修复的 `sharp` 版本，以修补本地模型构建工具的间接图像处理依赖；它不改变扩展内已打包的浏览器推理库版本。

常用脚本：

```sh
npm run demo             # 使用 Bun 启动本地演示
npm run local-model:build
npm run frequency:build
npm run release:package
```

`npm run release:package` 只接受干净且已经提交的 `HEAD`，按 `package.json` 当前版本生成 `dist/relyless-<version>.zip` 和 `dist/SHA256SUMS`。Release ZIP 只包含可运行的 `extension/`、`connector/` 和根目录 README、双语隐私政策与许可文件，不包含 `node_modules`、测试或开发工具；未启用的视频字幕线（`VIDEO_SUPPORT_ENABLED=false`）通过 `export-ignore` 排除在归档外。

目录概览：

- `extension/`：Manifest V3 扩展、界面、本地模型与运行时资源。
- `connector/`：ChatGPT、Grok 及 Google（Antigravity）订阅 Native Messaging 连接器。
- `tests/`：由 Bun 运行的回归测试。
- `tools/`：本地模型、词频、演示和发布包构建脚本。
- `docs/`：项目设计资料。
