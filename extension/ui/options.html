使用说明

从你读不顺的地方开始，不必先记住一套功能名。

RELYLESS · 阅读指南

词义卡住，看注释。长句绕住，看解构。

注释帮你理解一个词在这里是什么意思；阅读解构帮你看清一句话里谁在做什么、哪些部分是补充。两者可以配合，也可以只开需要的一个。目标是接着读原文，而不是把页面换成中文。

第一次使用：先到 模型服务 连接订阅服务或 API 并测试连接。自备 API 可一行填写一个密钥并逐项检查；只用一个密钥也兼容。再打开普通 HTTP 或 HTTPS 英文文章，点击扩展图标，在弹窗中开启本页或打开「阅读解构」。浏览器内部页和扩展页无法开启阅读辅助，弹窗会显示使用说明入口。需要的网站可在 网站规则 设置自动开启。

只想先看原文：在普通 HTTP 或 HTTPS 文章的弹窗点「进入专注阅读」，无需连接模型或开启本页辅助。扩展在本页本地提取正文快照，暂时隔离网页布局；无法可靠识别时不会改动原页。按住查词键单击正文英文词可主动求助，不会开启自动提示；需要模型时服务不可用会显示错误。原页已有双语译文会暂停并保留，退出后可继续。原页与专注阅读共用词档案及会话帮助缓存；同词同语境可复用，语境不同仍需核对当前词义，不会自动贴出所有历史释义。顶部的「翻译本页」会先显示用量估算，确认后只翻译读到附近的快照正文；也可调整字号、栏宽、行距和明暗主题，点「退出专注阅读」或按 Escape 返回原页。媒体及尚未加载的图片请回原页查看。

01 · 注释

读到一个词，不确定它在这里是什么意思

比如读到下面这句，只有 latency 绊住了你。先看一条短释义，能读通就继续，不必翻译整个段落。

  1. 主动查这个词：按住 D 并单击可见英文词语，包括专注阅读中的正文（即使没有开启本页自动辅助）、原页正文、其他链接、侧栏与控件文字，可打开词义卡；导航链接则直接显示整条中文标签，不出现卡片。普通点击保持网页原有行为；输入区打字不会触发。
  2. 选适合自己的呈现：在 阅读偏好 选「解释卡片」，可以继续看语境；正文词也可选「顶部释义」，意思直接放在原词上方。普通链接、侧栏和控件文字始终使用解释卡片，不改写网页控件。解释语言可选中文或简明英文。
  3. 一条释义还不够：使用解释卡片时，可点「用中文说明」，展开「本句翻译」查看中文句译和详细语境，或在追问框继续问当前表达为什么这样用。追问只带有限上下文和最近几轮问答；补充、追问或重试可能产生新请求。
  4. 复制干净原文：选中段落里的文字，右键选「RelyLess：复制选中段落的原文」。复制的是原始英文，提示、词注和译文都不会混进去。
  5. 翻译选段：选中正文后点击出现的「翻译所选」；只选中一个单词时可点「翻译本段」。浏览器没有预设的翻译快捷键。
  6. 导航词语与整条链接：按住查词键单击导航链接上的英文词，会直接在原标签旁显示整条中文译文；再次按键单击原文撤下译文。普通单击仍打开链接。

也可以让注释先来帮你：在「阅读偏好」选择「自动给少量提示」。本页辅助开启后，系统在可识别的正文中挑少量可能需要帮助的位置，不会逐词加注。滚动到新内容时可能提前请求模型；只想自己决定何时查词，就选「只在主动求助时」。

有原词标记，却没有上方释义？

标记只是提醒你留意这个表达。已确认的用法可能处在标记态：先不附释义，需要时仍可按住查词键单击。也可能是待确认：记得你查过这个表达，但还没确认它在这句里的意思，因此不会直接套用旧解释。

卡片里的「旧参考义」或「本地参考义」也只是参考。若当前上下文不足，选中包含该表达的完整句子再求助。原词标记、上方词注和译文的颜色、字号，可到 显示与解构 分别调整。

02 · 阅读解构

每个词都认识，连成一句却读不顺

这时需要的不是更多词义，而是看清句子的骨架。阅读解构用彩色下划线标出主语、谓语、宾语以及修饰部分，帮你先读主干，再把条件和补充接回来。

  1. 开启：打开扩展弹窗，打开「阅读解构」。页面可见、未暂停且模型服务可用时，它会分析正文并画出结构线。
  2. 读结构：先沿着主谓宾看意思，再看修饰部分。点击结构下划线，可打开「本句解构」查看带成分名称的层级，不必死记颜色。
  3. 嫌密或想看更细：到 显示与解构 的「句子结构」调整。粗粒度突出大结构，中粒度显示句子成分，细粒度最多展示两层；切换粒度、实线或虚线只改变显示，不额外调用模型。

结构线不是生词标记。颜色表示句子成分，不表示难度或熟悉度。解构和注释独立：即使词汇辅助选了「只在主动求助时」，已开启的解构仍会分析正文、产生模型用量。不需要时，在弹窗里关闭它。

03 · 已经能顺着读了，想让提示少一点

能读通时，不必逐个点开注释。RelyLess 的提示会逐步退后；这只是减少打扰，不是一次“已经掌握”的判定。

一个词已经认识，不想再自动看到它
在词注旁或解释卡片里点「我已认识」。保存后，这个词已有的标记、自动词注、手动词注和解释卡片会撤下；其他词的注释与段落译文保持原位，不重译整页。它也影响跨领域的同词与可识别词形，不只针对当前用法。误点可在 8 秒内「撤销」，以后也可到 提示偏好 → 已认识词 恢复；仍能主动查词。这个用法到期且再次出现在当前阅读区域时，页面右下角会出现「复习 N」，选择「认识了」或「还不熟」即可，本地复习本身不发送页面内容。
只是当前这个意思不需要提示
在解释卡片的「更多」中选「少提示这个用法」，只让当前用法安静下来，不把这个词的所有意思都藏起来。这个选择不因久未遇见自动解除；再次求助或恢复自适应可让帮助回来。
想完全由自己决定何时求助
在 阅读偏好 选「只在主动求助时」，停止自动词汇扫描、解释预备和遇见计数，保留按键查词、选段翻译。若还开着阅读解构，需要另外关闭；阅读记录也有独立授权。
没手动调整，为什么同一个词的提示也会变少？

开启「记住求助词与支持偏好」且记录可用时，同一词条、领域和用法会从带短注的提示态，退到只留原词标记的标记态，再到不主动显示的静默态。不是按一个词在页面上出现了几次来隐藏。

  1. 默认累计 3 个有效遇见日后只留标记；再累计 3 个标记态遇见日后，暂缓提示 7 天。
  2. 暂缓结束通常回到标记态。期间至少有 2 个有效遇见日，下一轮可延长到 14 天，再到 28 天；放着不读不会升级。
  3. 成功求助并保存后，该用法回到提示起点；超过 14 天没有有效遇见，也会重新给提示。

“有效遇见”要求已确认用法在前台连续可见至少 2 秒且记录成功；同一用法按 UTC 日界每天最多一次，主动求助过的同一页面不计独立遇见。关闭记忆或记录不可用时，不依赖个人词档案推进渐退。

以上是默认规则，不覆盖「少提示这个用法」或已锁定的手动状态。阅读记录里的锁定选择不会因再次求助自动解除；启用的个性化策略也可能调整提示深度，可在 提示偏好 查看。

04 · 还是读不通，或者现在只想先知道大意

不用勉强自己只看英文。先求助眼前这一句或这一段，读通后再接着读。

  1. 一句或一段：选中需要理解的正文，再点击出现的翻译操作。点击后才发送选段，译文与英文一起保留。
  2. 导航看不懂：开启本页后，按住查词键单击导航链接上的英文词，或在链接上右键选「RelyLess：翻译导航链接文字」。只发送该链接的英文文字（最多 200 字符），译文直接显示在原标签旁；原文及链接保持可用。普通按钮和输入区不参与。
  3. 视频字幕：播放、展开字幕和滚动本身不调用模型，主动请求翻译才调用。字幕里的生词也可以单独求助。
  4. 本页都吃力：在扩展弹窗的「本页双语翻译」区域，或在专注阅读顶部点「翻译本页」并单独确认。英文会保留，只处理读到附近的正文；可以停止、继续、重试失败段落或「返回英文」（专注阅读中为「返回原文」）。停止不能撤回已发送且可能计费的请求。

如果你等的是自动词注，却一直没出现：先确认本页已开启、服务已连接。正文无法可靠识别、词已设为认识或提示策略较安静，也可能不显示。导航、输入区、代码等不会当作普通正文；导航链接文字可在链接右键菜单主动翻译。没有标注不代表整页已分析，更不代表你已经认识所有词。请求失败时到 运行诊断 查看。

05 · 准备读工作资料，先确认哪些内容会发送和保存

本地优先，不等于完全离线。注释、解构和翻译的模型请求会发送给你选择的 ChatGPT 订阅服务或 API。普通辅助可能包含目标词句、标题、章节与上下文；自动预备的文章上下文最多 12,000 字符，短文章可能整体包含在内。敏感页面不要自动开启，也不要把不允许外发的内容提交求助。

  • 只想记住查过什么：「记住求助词与支持偏好」默认开启，在本机保存词条、简短释义和支持偏好，不保存原句、标题或来源网址。关闭后不再读取或更新，已有词档案不会自动删除。预备解释与有限上下文另放在当前浏览器会话缓存中。
  • 想回看读过的内容：阅读记录需要单独开启并添加允许的网站，可保存查询、原句与来源等信息；关闭采集不等于删除历史，无痕页面不采集。
  • 想让系统总结或调整提示：摘要与个性化需要独立授权，不随词档案开关开启。远程领域识别也需另选，默认在本地识别领域。

先在 网站规则 限定自动开启范围，单站点规则优先于「全部网站」，本页暂停时不自动运行。导出或清理已有数据，到 数据与隐私。

06 · 服务不稳定，或者想把重要请求交给更强模型
  • 多个 API Key：在 模型服务 的密钥框中一行填写一个密钥，最多 8 个。保存后按权重轮询；认证、配额、限流或临时故障会触发切换。使用「逐项检查密钥」可以单独验证每一行，不受当前冷却状态影响。
  • 模型路由：默认关闭。开启后，Jev 只判断你勾选的主动求助、选段或整页翻译、追问等高价值请求；普通自动词注不判卷，阅读解构默认也不判卷。升级目标不可用或判断失败时回落当前服务。
  • 先看清成本：判卷本身也会发起一次模型请求；升级后由目标服务处理正式请求。密钥、端点和升级服务都由你管理，统计区会显示判卷、升级、失败和缓存命中次数。
