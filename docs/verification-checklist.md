# 手动冒烟验证清单

覆盖本机无法自动验证的浏览器行为。每条都给了预期结果；不符合即回归。

## 0. 准备

1. `chrome://extensions` → 打开开发者模式 → 加载已解压的 `extension/`。
2. 任意测试页点工具栏图标，打开「阅读辅助」开关；新安装不预设扩展组合键。
3. 开启前先看 DevTools Console 是否有报错（选项页此前的 `automationSiteEmpty` 报错已修复）。

### 0.1 弹窗单屏操作

- 阅读辅助与阅读解构都是原生开关：点击标题或用 Tab/Space 切换；失败回到最后确认状态，不修改网站长期规则。
- 专注阅读与全文翻译并排位于底部；专注阅读进入/退出原页，全文翻译先确认数据与费用，取消或 Escape 返回原入口。未连接服务时仍可专注阅读，翻译禁用且有服务设置入口。
- 浅色与深色主题无滚动条，全部操作按钮和风险文字在浏览器 600px 上限内。受控界面状态覆盖七项任务、600 字符长错误、网站提示、翻译进度及超预算二次确认；不能靠裁剪按钮通过。长反馈的悬停全文与读屏文本均保留。

### 0.2 实色界面

- 在浅色与深色主题检查 popup、设置、网页帮助卡、专注阅读和 PDF：文字承载面与操作按钮均为实色，无毛玻璃、半透明底或 opacity 淡入；禁用控件 opacity 为 1，键盘焦点清晰。
- 按住查词键悬停正文词只显示描边，松键移除；PDF 文本块悬停或操作按钮获得焦点时只描边，不覆盖画布文字。PDF 文本层仍可选择，关闭专注阅读后扩展视图移除、原页可继续使用。

## 1. 分级语言闸门（决定是否开始扫描）

| 页面 | 预期 |
|---|---|
| 英文文章页 | 出现词注/提示，地址栏旁图标可点；上下滚动并等待后台准备完成后，已显示的词注不会自行消失 |
| 纯中文页 | 无任何提示；DevTools Network 无 `SUPPORT_BATCH` 请求 |
| 德文/法文/西班牙文页 | 无提示（识别为非英语即停） |
| 中文文章里嵌英文段落 | 英文段落有提示，中文段落没有 |
| 纯数字/乱码页 | 无提示、无报错 |

验证技巧：DevTools → Network 过滤 `SUPPORT_BATCH`/`SENTENCE_GROUPS_BATCH`，非英文页应为 0 次。

## 2. 划词浮条

1. 选中一句英文 → 浮条出现（翻译所选 / 翻译本段）。
2. 点「翻译所选」→ 译文面板出现；再点原文其他位置，浮条不自动回到同一选区。
3. 按 `Escape` 关浮条 → **在原选区内点击/松手，浮条不重新弹出**；重新划选别处，正常弹出。
4. 设置 → 阅读偏好 → 划词动作打开方式选「悬停等待」→ 鼠标停在「翻译所选」上 600ms（默认）自动打开；中途移开取消。
5. 把悬停等待改成 200ms / 3000ms 各试一次，保存后生效。

## 3. 快捷键与选段入口

1. 新安装时扩展不占用任何浏览器组合键；`chrome://extensions/shortcuts` 显示浏览器自带的「激活该扩展程序」及可自行绑定的「开启或暂停当前网页」，两者均未设置。绑定后触发本页状态变化；Mac Option（⌥）在设置中也叫 Alt。
2. 选中正文 → 点击浮条「翻译所选」或「翻译本段」；本页双语翻译仍需在弹窗或专注阅读顶部单独确认。
3. 开启本页，按住查词键单击导航链接 → 直接在原标签旁显示整条中文译文，不出现词义卡或独立浮层；再次按键单击原文撤下译文，普通单击链接仍能跳转。右键菜单也只处理当前链接（最多 200 字符）。其他链接、侧栏文字和按钮标签仍只解释命中的英文词，不触发链接跳转或按钮操作；输入区、可编辑内容、隐藏文字和代码块不求助。普通链接、按钮、变更 URL 的导航链接不能使用整条导航翻译。

## 4. 段落干净复制

1. 选中英文句子 → 右键「RelyLess：复制选中段落的原文」→ 剪贴板是整段纯原文，不含提示、词注和译文。
2. 选中注入提示的段落 → 同样不复制扩展内容；代码块没有可复制段落，不发起复制。

## 5. 站点规则包

1. 设置 → 网站规则 → 粘贴合法包（输入框 placeholder 里的示例）→ 导入成功，列表出现一条。
2. 粘故意写坏的包（如 `exclude:["div[坏"]` 或 `version:2`）→ 导入被拒并逐条显示原因。
3. 导入一条 `exclude:[".sidebar"]` → 访问该站点，侧栏内英文不再有提示；其余站点不受影响。
4. 导入带 `root:"main"` 的包 → 该站点正文识别优先使用 `main`。
5. 带 `lang:"en"` 的包 → 该站点跳过语言检测直接启用（可用一个混合语言站点验证）。
6. 删除规则包 → 行为恢复默认。

## 5.5 追问会话（新）

1. 按住查词键单击一个单词 → 卡片底部出现追问区（输入框 + 追问/停止按钮）。
2. 输入“这里为什么用完成时？”→ 回车或点追问 → 回答**流式**出现在该问题下方；生成中可以点“停止”，已生成部分保留并标“已停止”。
3. 再问第二个问题 → 回答体现上一轮上下文（多轮生效）。
4. 关闭卡片，重新查同一个词 → 历史问答原样恢复（30 天本机保留）。
5. 查同一个站点另一个页面里的同一句话 → 会话不串。
6. 未配置 API 服务时追问 → 卡片里给出明确错误，不崩溃。
7. `providerKind=chatgpt`（SIWC 已登录，新连接器已安装）时追问 → 多轮正常：每轮 `input` 带新问题及所需有界历史，不出现 Codex thread、远端 `conversation` 或 `previous_response_id` 续接。重启主机后继续同一追问 → 用扩展提供的有限已完成回合重建上下文；不同选文/账户不串会话。旧连接器 → 明确提示升级，不能静默退回 Codex。
8. 隐私窗口追问 → 功能可用但不落盘（重开普通窗口看不到该问答）。
9. 设置 → 阅读记录 → 「对话」标签 → 看到按会话分组的问答（页面标题、选文、每轮问答、删除按钮）；删除后卡片内的历史同步消失。

## 5.6 追问的本地记忆

1. 对一个查过多的词追问“上次怎么讲的？”→ 回答应衔接你此前的笔记（卡片里出现“已结合你过去的 N 条笔记”）。
2. 对新词追问 → 不出现该提示，回答只依据选文与上下文。

## 5.7 间隔重复复习

1. 在一个已有提示记录的词所在页面滚动/停留 → 右下角出现“复习 N”按钮（1 天后该词到期时）。
2. 点按钮 → 面板列出到期词与盒数；点“认识了”→ 该项消失、间隔拉长（3/7/21/60 天）；“还不熟”→ 当天稍后再来。
3. 主动再查一个已排期的词 → 计划重置到第 1 盒（视为遗忘）。
4. 设置里清空本机记录 → 复习入口不再出现（计划键随清理移除见“数据与隐私”）。

## 5.8 Jev 领域识别（Requesty / SiliconFlow）

1. 设置 → 领域识别 → 选“Jev 判定”→ 「判定接入」默认 Requesty → 填模型 `typesafe/jev-1.13.0`、接口地址与 API Key → 保存（首次会请求 router.requesty.ai 权限）。
2. 「判定接入」切换到 SiliconFlow · System One → 接口地址与模型自动换成硅基流动默认值（`https://api.siliconflow.cn/v1`、`diffusiongemma`）→ 填硅基流动 API Key → 保存（首次会请求 api.siliconflow.cn 权限）。
3. 打开英文文章 → 领域识别使用所选判定服务；诊断里 source 显示 `jev`，带置信度分数。
4. 留空模型或 Key 保存 → 明确报错；返回的领域不在支持列表 → 按远程失败回退本地结果（有 warning）。
5. 清除密钥后 → 权限来源里不再包含相应判定端点（router.requesty.ai 或 api.siliconflow.cn）。

## 5.9 模型路由（实验）

前置：领域识别里已选好判定接入并填好模型/地址/Key（路由复用同一份凭据）。

1. 设置 → 模型服务 → 「模型路由」打开开关 → 选升级目标（某个已保存服务或 ChatGPT 订阅）→ 保存。
2. 打开英文文章主动查一个词 → 若被判为 premium（段落/救援级/难内容），请求打到升级服务；「统计」行显示“已判 1 次 · 升级 1 次”。
3. 对同一句子再查一次 → 不再判卷（结果缓存或路由缓存命中，统计的“已判”不增加）。
4. 把 Jev 的 Key 清空 → 判卷不可用，请求照常走原服务，统计“判卷失败”或“未启用”。
5. 升级目标选一个没有 Key 的服务 → 自动回落原服务，不报错。
6. 关闭开关 → 统计归零重启，任何请求都不再判卷。

## 5.10 多 Key 轮询

1. 设置 → 模型服务 → 编辑 API 服务 → 「API Key」文本框每行贴一个密钥（最多 8 个，自动去重）→ 保存。
2. 保存后「密钥状态」显示“已保存 N 个密钥；请求按权重轮询，失败自动切换”。
3. 点「逐项检查密钥」→ 逐个返回可用/不可用及原因（单 Key 检测不占用轮询冷却）。
4. 用一个无效 Key + 一个有效 Key 保存 → 正常请求仍然成功（自动切换到可用 Key）。
5. 只留一个 Key → 行为与之前完全一致（零开销）。
6. 错误提示中不出现任何密钥明文。

## 5.11 本机模型（Gemini Nano）

前置：Chrome 支持内置 Gemini Nano（`LanguageModel` API 可用）。

1. 设置 → 模型服务 → 选择「本机模型」卡片 → 右侧面板显示 Nano 状态；状态为「待下载」时点击下载按钮，可见进度并变为「已就绪」。
2. 保存后对一个单词做简短提示查词 → 卡片标注「本机模型生成」，诊断里 provider 为 `local`，不发起网络请求。
3. 同一设置下触发整页翻译/追问 → 回落到已就绪的 API 服务或已登录订阅；两者都没有时给出明确报错而非静默失败。
4. 下载未完成、设备不支持或 Nano 响应格式无效时查词 → 自动回落远端服务，诊断记录 `LOCAL_FALLBACK`；远端提示不标注「本机模型生成」，本机用量记失败。
5. 用量统计中本机调用记为「Gemini Nano（本机）」，不计 token 费用。

## 5.12 键盘导航

1. 设置 → 阅读偏好 → 打开「键盘导航」。
2. 在有标记词的页面按 `]` / `[` → 视口滚动到下一个/上一个标记，词上短暂描边闪烁，状态行提示「按 X 打开解释」。
3. 按查词键 → 打开当前选中标记的解释卡；Esc 或点击页面 → 退出导航态。
4. 关闭开关 → `]`/`[` 恢复原站点行为（裸键不与页面快捷键冲突）。

## 5.13 专注阅读（当前页本地正文快照）

1. 无模型配置、未开启本页辅助时打开英文章和中文文章 → 弹窗底部「专注阅读」可用；正文原文顺序、标题、列表、链接与脚注保留，不触发模型请求。歧义正文、过短页或超限页给出可聚焦错误并留在原页。
2. 进入后用 Tab/Shift+Tab 在工具栏、正文链接间移动，Escape 或退出按钮返回原页；原页输入值、焦点、滚动、事件监听与原 DOM 不变。字号、栏宽、行距和明暗主题在 320px、200% 缩放、浅深色页面均无横向溢出。真实含脚注与表格的文章：视图内链接可读且可聚焦，空装饰链接不可聚焦，空表头不虚构标题；键盘 Enter 到页内脚注仍留在视图内、不改原 URL；针对视图单独运行 axe。
3. 专注阅读在本页辅助关闭时按住 D 单击英文正文词 → 显示帮助卡，松开或继续按住 D 都能看到最终结果；原页未被动扫描、预取或记录。开启自动辅助后切换视图 → 旧原页注释和迟到模型结果不落入快照，查词卡、选段、结构线和复制只服务当前表面；关闭视图后原页重新按既有模式工作。同词同语境在原页与视图分别主动求助，结果和已保存词档案复用；不同语境不能将旧义冒充为新确认结果。失败详情可从状态提示进入，自动提示失败短时消失，不把泛化“阅读尚未完成”长期盖住正文。
4. 原页双语翻译进行中进入视图 → 原页停止发新请求但已译内容保留；本页自动辅助被暂停时，视图顶部「翻译本页」仍作为单独明确动作先显示估算、再确认，超预算再确认；仅快照可见附近正文出现双语，停止保留已译，返回原文仅清理视图，退出后原页译文仍在且可继续或清除。站点导航、源正文或视图容器被删除、关闭本页辅助会移除视图，设置刷新保留视图与滚动位置；已加载图片与未加载图片/媒体分别显示安全副本或回原页说明，链接和脚注可用，危险 URL/事件属性不执行。
5. 长文章在原页和专注阅读分别确认翻译 → 首屏各段以独立原文段落配对显示，附近两个有界批次可同时请求；一批失败时另一批已验证成功的译文仍可见，之后停止派发。停止、正文变化或退出时失效结果不得落到当前表面。远处正文仍只随阅读位置按需处理。
6. 同时挂起两个批次，让第一批先完成、第二批保持延迟 → 第三批立即占用空闲槽，不等待第二批；请求上限设为1时不并行。隐藏页面、正文重扫、停止后继续或更换会话期间，旧请求仍计入上限，迟到 finally 不得重置新请求。
7. API/ChatGPT/Grok 的流式前缀先显示为未确认译文（aria-busy=true），已译计数仍为0；完整响应通过校验后替换并计数。断流、无效终态、停止、正文变化与伪造 token/requestSeq/重复ID 不得留下伪完成译文；其他已确认分块保留。Antigravity CLI 不要求 token 级预览。长段落超过4000字符时核验连续分块的同段前后文及否定、数值、术语保持。

## 5.14 PDF 阅读器

1. 未开启「在 RelyLess 阅读器中打开 PDF」时点击 .pdf 链接 → 原生查看器接管；右键「RelyLess：在阅读器中打开 PDF」→ 单次进入内置阅读器；网址加 `#relyless-native` → 单次回退原生。
2. 开启设置后打开 .pdf → 重定向到 `pdf-viewer.html`；页面渲染、文本层可选中；跨域站点先直接拉取，失败再出现「授权访问」按钮，拒绝后可改原生查看器。
3. 单击单词 → 求助卡片（默认英文提示，可点「中文释义」，推理模型可能需等待并有进度提示）；选中文字 → 「翻译选段/解释选段」浮条，Escape 或点击空白处关闭。
4. 块上「译」（悬停/聚焦原文块时显现）→ 译文附在原文块下方并写入右侧对照栏；「翻译本页」→ 预算估算与确认流程后逐块送译，对照行可点击或 Tab+Enter 回跳高亮原文；缩放、翻页后已译块保留；超预算时状态条给出「仍然翻译/取消」选择。
5. 双栏 PDF 左右栏不混排；通栏标题作为水平分隔带自成一块且不搅乱栏序；超过 4000 字符的块在对照栏显示「未送译」并计入状态，选段超长时明确拒绝而非截断；401/403 提示先登录或回退原生；无服务配置时各入口明确报错；Console 无报错。
6. 小页翻译完成后切到更大且超预算的第二页 → 必须重新显示预算确认；取消后第二页不发送请求，确认后仅发送新页待译块。快进 PDF → 普通网页，迟到的重定向不能把普通网页改回旧 PDF。
7. 读取超过 64 MiB、超过 500 页或物理画布超过 1600 万像素的文档 → 明确提示使用原生查看器，不能挂起页面或继续分配无限内存。

## 5.15 ChatGPT SIWC 开源 OAuth 与直接 Responses

前置：本机 Node.js 20+，按 README 用实际扩展 ID 安装 Native 主机；合资格的 Plus/Pro 账户。无需 Codex CLI；用未安装 Codex 的环境覆盖安装和连接检查。以下是验收场景，不代表已经执行。

1. 设置 → ChatGPT 订阅 → 发起登录 → 打开 OpenAI 授权页；完成明确授权后，临时 loopback 回调只到本机主机，账户与模型刷新成功。拒绝授权、登录超时、回调 state 不匹配或 ID token 验证失败 → 保留真实错误，不显示就绪，不开始推理。
2. 升级旧连接器后重新运行安装命令并 SIWC 登录 → 不读取 Codex 凭证，不查找 `codex`/`codex.cmd`。用错误扩展 ID 或来源尝试连接 → 被拒绝；Grok 安装也不检查 CLI，Antigravity 保留现有 CLI 安装检查。
3. 主机接入受控 OAuth/HTTP 夹具检查消息和文件 → `siwc.json` 只在主机数据目录，POSIX 权限 0600；浏览器存储、Native 返回值、诊断与导出无访问/刷新令牌、授权码或 PKCE verifier。不得在测试报告中粘贴真实凭证。
4. 用已授权账户检查连接并主动求助 → 主机直接访问 OpenAI Models/Responses；Responses 使用 OAuth Bearer、`store:false`、`stream:true` 与 `input` 数组，不含 `previous_response_id`、`conversation`、`temperature`、`max_output_tokens` 等不支持字段。目录存在不等于模型权限保证；实际推理失败应如实显示。
5. 受控 SSE 分片覆盖 delta、`response.completed`、`response.failed`、`response.incomplete`、提前 EOF → 只有明确完成且结构化结果有效才提交成功；断流或失败不缓存伪成功，不把部分全文译文当作完成。正常追问保持进度；停止后迟到结果不覆盖已停止状态。
6. 同一选文连续追问与另一个选文交错 → 历史隔离；主机最多 50 会话、每会话最近 12 组问答，闲置 30 分钟失效。账户切换、退出登录、主机退出 → 清除主机内历史；扩展普通窗口仍遵守 30 天/40 轮记录边界，无痕不落盘。
7. 令牌过期 → 主机刷新；刷新被撤销、计划用量未授权、额度不足、模型无权限或网络不可用 → 明确错误，不泄露原始响应中的秘密，不静默改为 API Key 计费。用户显式配置的既有故障转移仍按其配置与确认边界工作。
8. 清空扩展阅读数据 → 不冒充 ChatGPT 退出；订阅面板退出登录 → 清除本机账户授权，重新求助提示登录。ChatGPT 设置撤销应用访问后再调用 → 不继续显示可用。Grok/Google、API 服务的登录、连接与已有核心求助场景仍正常。

## 5.16 Grok 兼容设备码 OAuth 与订阅代理直连

前置：Node.js 20+，实际扩展 ID 安装 `--backend grok` Native 主机；明确接受公开 CLI 客户端复用不等于官方第三方支持。以下均是待验收场景，不代表已执行；真实登录、授权、撤销与付费调用需用户另行明确授权。

1. 未安装 Grok CLI 的环境安装和连接 → 不查找或执行 `grok`/`grok.cmd`；旧 Grok CLI 数据不读取、不删除，Google 既有配置不迁移、不删除。从旧 CLI 通道迁移时要求新的设备码登录，不导入旧认证；后续主机更新保留有效直连授权。错误扩展 ID/来源仍拒绝。
2. 设置 → Grok 订阅 → 登录 → 只打开主机提供的可信验证地址并显示短用户码；主机轮询。拒绝、过期、取消、`authorization_pending`、`slow_down` 与网络失败 → 状态符合设备授权协议，不显示伪成功；旧轮询迟到不得覆盖新登录或退出。
3. 受控 OIDC 夹具 → 官方 userinfo 身份与必要 scopes 验证；返回 ID token 时验证 ES256 签名及 issuer/audience/subject/有效期并核对 userinfo subject；无效签名、账户变化、过期或缺少 `grok-cli:access`/`api:access` 均拒绝。未验证 JWT 解码不能建立可信身份。
4. 凭证轮换与并发刷新夹具 → `grok-oauth.json` 仅在 Native 数据目录、POSIX 0600、原子替换且保留新轮换刷新令牌；浏览器存储、Native 消息、网页、诊断、导出和错误无令牌、device code 或完整原始身份响应；无请求提示词文件。
5. 模型与账户目录夹具 → `/models-v2` 使用订阅代理，账户身份使用授权服务 `/oauth2/userinfo`，隐藏/API-key-only/不适用 Responses 的目录项不显示；列表不代表访问保证。请求身份与 UA 如实标识 RelyLess，`X-XAI-Token-Auth: xai-grok-cli` 只表示兼容认证方案，无来源冒充。
6. 受控 `/responses` HTTP/SSE → 正常完成才提交；覆盖分片、failed/incomplete、提前 EOF、无效结构化结果、超限和取消，未完成内容不缓存为成功。请求 `store:false`，不宣传零保留、不新增 Grok 追问会话。
7. 过期令牌刷新、撤销、401/403、套餐/权益不足、限额、模型无权限及网络故障 → 保留真实错误类别，不新增自动推理重试，不自动改为 API Key 支出；用户显式配置的既有故障转移保持原边界。
8. 清理扩展阅读数据 → 不冒充 Grok 退出。订阅面板退出 → 本机授权清除，远端撤销尝试；远端失败也保持本机已退出并如实提示。退出中旧刷新/推理迟到不得恢复账户；再次求助要求登录。
9. ChatGPT SIWC 和既有 Google 配置回归 → ChatGPT 协议不改变，Google 不迁移/删除；界面/文档显示官方 Antigravity FAQ 的第三方访问限制及账户风险，不宣称官方允许。

## 6. 文档类网站提示

1. 图标提示默认关闭：访问 docs.python.org 等站点，扩展图标无提示徽标；但打开弹窗，命中关键词的网站仍显示提示文案与「不再提示此网站」。
2. 设置 → 网站规则 → 开启「同时在扩展图标上提示」→ 打开域名含 docs/learn/wiki 等片段的网站 → 图标出现紫色「+」，悬停标题说明可开启自动辅助。
3. 打开域名不含关键词的网站 → 徽标消失；paradocs、readthedocs 类非整段匹配不提示。
4. 弹窗中该站点显示提示文案 → 点「不再提示此网站」→ 徽标消失，该 origin 出现在设置忽略列表；设置中「恢复提示」后再次访问重新出现。
5. 弹窗中开启「此网站以后自动开启」→ 徽标消失且不再提示该站。
6. 设置中修改关键词（如只留 wiki）→ 不再命中的域名停止提示；关闭图标提示开关 → 所有徽标清除，弹窗提示不受影响。
7. 优先级：在命中站点上让图标提示开启且某操作失败显示「!」→ 提示不覆盖错误；随后成功操作清除「!」且仍命中时恢复「+」；跨文档导航丢弃错误状态并按新网址重新评估提示。

## 已知边界（不是bug）

- 追问多轮支持 API 服务与 SIWC ChatGPT 订阅连接器（旧连接器会提示升级）；Grok / Antigravity 订阅暂不支持追问。ChatGPT HTTP 每轮重发有限历史，不提供远端持久会话；「停止」后已发出的请求可能继续执行或计费，迟到结果被丢弃。
- 追问记录不随阅读记录导出（两套存储；导出文件只含阅读事件）。
- 视频字幕线仍未启用（`VIDEO_SUPPORT_ENABLED=false`）；启用前需在真实 YouTube 页面按「播放页 → SPA 进入 → 字幕开关」三步实测。
- 英文页中完整的德语/西语段落仍会获得提示（块级判定基于字符占比）。
- 如需浏览器级命令，只能自行给本页开启／暂停绑定组合键；选段翻译不占用浏览器快捷键。
