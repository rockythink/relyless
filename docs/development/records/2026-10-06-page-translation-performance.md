- 日期：2026-10-06

## 背景

用户实测反馈陪读蛙的全文翻译速度与效果更好。本次接受该观察，不重复对比产品以质疑反馈；测量并修复本扩展已存在的整轮等待、页面进度传输缺口和长段落切块上下文问题。

## 目标

- 流式服务在最终响应前即可显示有界未确认译文。
- 一个慢请求不闲置另一个已释放的槽。
- 连续长段落分块有切块处的同段前后文，要求忠实译文而非缩写摘要。
- 保持原文、用户确认、费用边界、并发上限、取消与失败诚实性。

## 非目标

不改默认英文优先方向，不扩大后台预译范围，不切换用户的服务或模型，不提高并发，不新增重试、权限、文章存储、全篇术语表或视频翻译。

## 实现边界

后台与 Native 主机复用既有翻译进度路径。内容脚本校验 session/token/requestSeq/generation、原文与上下文后显示临时纯文本片段；最终响应仍独立校验。滚动补位保留旧请求的全局在途计数；旧 runner 不得清理新 runner。失败只停止后续派发，不丢掉其他已在途批次的确认结果。

长段落的内部切块前后文来自同段相邻分块，首尾沿用邻段，各400字符以内；有效性签名仍基于原单元。Google（Antigravity）的现有 CLI 仅在最终解析后回调，不声称 token 级流式。

## 数据、权限与费用

无新增接收方、权限、模型档位或持久数据类别。原有每批最多四项、4000源字符及12000源文加上下文限制不变。预览不计入成功缓存或阅读记录。译文缓存版本1→2，旧策略的选段/本页结果不命中；已有词档案与阅读记录不变，冷缓存请求可能重新产生费用。

## 风险与回滚

预览可能最终失败或被替换，必须撤下未确认部分，不能宣称完成。同段其他确认分块要保留。停止后已经发送的请求仍可能计费。整体回滚对应运行时代码与文档；不能恢复旧策略命中来掩盖质量问题。

## 验证证据

### 自动与缓存

- `npm run check`：691 tests pass，0 fail，3724 assertions，48 files。
- 流式预览/停止/失败/已确认分块保留针对性回归：5 pass，0 fail。
- 一次性脚本实跑真实后台：分别预置版本1本页/选段缓存，均没有命中旧译文；新确认结果写入当前策略缓存；更换请求ID再次调用复用结果、不增加模型调用。两条路径合计仅两次初始受控调用。

### 浏览器受控计时

在 Chromium 中运行优化前快照与优化后真实 content、reader、background、API 流解析代码。Chrome API/IPC 边界使用隔离夹具，本地 HTTP SSE 提供固定延迟与合成译文；不是已安装扩展或真实订阅连接器全链路。16正文单元，1100×2400视口，同样4批、并发2。第2批固定3秒，其余900毫秒；流式前缀120毫秒到达。记录一次配对运行，不作为线上模型性能或译文质量证据。

### 表面、停止与失败

- 原页与专注阅读均检查浅色/深色实际截图，英文原文保持；专注阅读每个主题 axe 0 violations，2项仍需人工判定，不声称完整无障碍认证。
- 慢响应场景：点击真实工具栏停止后预览撤下；响应终结后仍为stopped、completed=0，仅原有两批，没有补发。
- SSE 明确错误：预览撤下，状态显示「服务返回错误，已停止请求」，completed=0，没有第三批。
- 原页关闭辅助后扩展拥有的 UI 数为0，原文保持。
- 浏览器记录中没有页面 JavaScript 异常；隔离 IPC 消息桥在闲置60秒后有 EventSource 断线重连，属于测试桥，不宣称网络日志完全无错误。
- 跨来源/代次/重复ID、部分失败保留成功批次、隐藏/重扫、停止后继续与长段落上下文另由既有模式的行为回归覆盖；本次未实跑真实 OAuth、Native Messaging、已安装扩展或 PDF 界面。

### 六次公开文本模型对照

经用户允许，取三段公开官方文档，各用旧/新提示词调用本会话默认模型一次，共六次；未调用用户配置的订阅账号，不发送私人网页或凭证。

- [MDN Fetch](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch)：网络失败与HTTP错误、Response.ok、抛异常。
- [PostgreSQL MVCC](https://www.postgresql.org/docs/current/mvcc-intro.html)：读写互不阻塞、SSI、最严格隔离。
- [Python truth-value testing](https://docs.python.org/3/library/stdtypes.html#truth-value-testing)：__bool__/__len__ 条件及异常传播。

六个响应均通过本页结果结构与语言校验。两组提示词都保留核心条件；新Python译文把两个方法对应结果表达更清楚，PostgreSQL新译文给出完整SSI名称。MDN新译文使用「200范围」，不如旧译文「200–299」明确。因此没有证据证明新提示词整体显著优于旧提示词，更没有证据证明已超过陪读蛙。此次质量改进是切块上下文与保真要求的修复，不作模型效果保证。
