# 开发记录：移除全局任务圈

- 日期：2026-10-04
- 状态：已交付
- 相关 Issue：[#54](https://github.com/rockythink/relyless/issues/54)
- 相关 PR：以关联 Issue 的任务反馈修复 PR 为准
- 相关 ADR：[0009](../decisions/0009-surface-owned-task-feedback.md)

## 背景

右上角固定任务组件在忙碌时缩为无文字且不可关闭的圆圈，仍拦截所占位置的点击。复现中原生按钮点击计数为 0，撤下组件后同位置计数为 1。

## 目标

普通网页不出现全局任务层；自动准备与解构状态转到 popup，主动求助与选段翻译的加载、错误和重试留在对应位置；工具栏以 `!` 提醒真实失败，优先于域名提示 `+`。

## 非目标

不重做阅读模式、模型服务、字幕或 PDF；不增加权限、自动请求、隐藏重试、持久阅读事件或掌握度指标。

## 实现边界

内容脚本内存保存七种任务键的有界状态，popup 校验 `SS_STATUS.tasks` 后以原生列表和 polite live region 呈现。专注阅读使用独立工具栏文本，不覆盖翻译确认。

service worker 接收有序的 `PAGE_TASK_STATUS`，严格验证主框架、原生 documentId、当前 URL 及异步文档代次。任务与右键错误分离，徽标更新共用标签页队列。局部求助捕获页面、代次、阅读表面和原文目标，导航、关闭或目标变化后不接受迟到反馈。

## 数据、权限与费用

没有新增浏览器权限、模型请求或远程发送路径。任务文字仅在当前内容脚本内存；会话徽标仅保存文档 ID、递增序号与错误布尔值，完整 URL 只即时校验。无痕不写持久数据，导航清错误、关页清会话元数据。两份隐私文档同步说明。

## 风险与回滚

后台失败需要打开 popup 查看具体文字；服务错误与右键错误的独立所有权、文档校验和序号水位防止旧请求误清或复活徽标。回滚应整体回退任务引擎、popup 与徽标消息协议，不能只恢复一个旧接口。

## 验证证据

- 首次 `npm ci && npm run check`：616 个测试通过，0 失败。全部生命周期修复后的最终 `npm run check`：652 个测试通过，0 失败，3420 个断言。
- 最终生命周期验收：真实服务未连接时，关闭失败选段译文后任务和徽标均清空；回归同时覆盖关闭旧面板不得清除较新的在途或失败翻译。
- 真实网页的“已认识”撤销错误通过临时消息夹具触发，点击关闭后提示、任务与徽标清空；只验证界面生命周期，不据此声称模型推理或词偏好持久化成功。
- 实际三秒临时错误在第二秒重复触发，首次期限之后仍显示错误与 !，重新计时到期后任务和徽标清空。夹具已移除，禁用后扩展自有节点为 0。
- 徽标回归覆盖可信 sender、字段边界、`!` / `+` 优先级、独立错误渠道、文档/序号变化、异步导航、无痕及关页清理；局部反馈回归覆盖加载、真实失败、重试、取消和原文失效。
- 加载完成后的扩展快照，在实际 Chromium 原生 popup 验证忙碌和错误文字；真实内容脚本发送状态，工具栏显示 `!`，会话记录只有文档 ID、序号、错误；清任务后徽标为空。
- 浅色和深色示例页面右上角原生按钮可点击，页面全局 `task-status` 节点数量为 0。
- 实际 popup 键盘 Tab 聚焦到专注阅读入口；修正列表语义后 axe-core 4.13.0 检查 0 违规、0 待确认。
- 专注阅读工具栏显示任务文字，退出恢复原页；实际查词在服务未连接时于原词卡片显示真实错误和重试入口。
- 主世界 SPA 导航后 `SS_STATUS.tasks` 为空、徽标为空；暂停后任务为空且扩展自有节点数量为 0。
- 忙碌与错误状态夹具只用于验证界面和生命周期；未授权模型账户、未发送付费请求，不据此声称模型质量或性能通过。
- 自动审查的五项 P2 均已修复：临时错误按期限到期，真实模型失败移除短期限；关闭求助卡清任务；History API 导航通知内容脚本；保留并存右键错误的具体标题；部分翻译失败作为错误，保留成功译文及重试入口。行为回归覆盖对应生命周期与并发竞态。
- 真实 Chrome 发现 SPA 的 sender.url 保留首次注入地址，以及 loading 与 URL 同时出现。修复后，原生 pushState/replaceState 不依赖 SS_STATUS 即清任务和徽标；新路由错误仍显示 !；同文档重复通知保留当前错误并重报；序号水位不倒退。
- 最终源码加载后，临时复制错误由 ! 转为空；无期限服务错误仍保留。原生 popup 截图与 axe-core 4.13.0：0 违规、0 待确认。暂停后任务为空、徽标为空，扩展自有节点为 0。
- 最终真实查词手势点击数字文本：原处显示“这里没有可解释的英文词”，工具栏先显示 !，三秒后任务与徽标为空，局部错误卡仍可收起；不调用模型。无效导航文本和无效查词手势恢复明确的三秒期限，与持久模型失败区分。
