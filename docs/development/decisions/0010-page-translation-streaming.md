# ADR 0010：本页翻译滚动补位与未确认流式预览

- 状态：accepted
- 日期：2026-10-06
- 参与讨论：用户全文翻译体验反馈；既有 [Issue #44](https://github.com/rockythink/relyless/issues/44) 边界
- 取代：无
- 被取代：无

## 背景

本页双语翻译虽允许两个批次在途，旧调度仍等待整轮 Promise.all 完成，慢请求会闲置另一个槽。API/SIWC/Grok 已有选段增量解析能力，但本页翻译没有将其传到正文。长段落切块沿用整段邻居，缺少切块处的同段前后文。

## 决策驱动因素

- 缩短首字可见等待，消除慢批次造成的空闲，不提高并发或后台预译整篇。
- 预览不能被当成已完成、写入成功缓存或逃逸来源与取消边界。
- 不新增权限、接收方、重试、模型选择或推理档位策略。
- 复用现有 Native 进度事件、内容消息和译文容器，不形成第二套协议与 UI。

## 备选方案

### 方案 A：提高并发或扩大整篇请求

可能改变成本、限流压力及已有用户确认的数据范围；不采用。

### 方案 B：保持现有上限，滚动补位并转发有界预览

允许已有两条流水线独立前进，增加临时预览状态与终态清理职责；采用。

## 决策

1. 按阅读位置选择附近正文，任一批完成即可补充空闲槽；最多两个批次，用户设置更低时服从较低上限。旧代次尚未结算的请求也计入在途上限。
2. runner 按 session/generation 持有；停止、隐藏和正文重扫不能让旧 runner 的清理覆盖新 runner。单批失败停止新派发，但已在途的成功结果继续校验并保留。
3. API、SIWC、Grok 的本页增量复用 translationProgress 与 SS_TRANSLATION_PROGRESS。后台定向到授权文档，内容脚本按 token、requestSeq、generation、原文、上下文及批次 ID 核验。
4. 预览只作纯文本 DOM 展示，带 aria-busy 与未确认说明，不累计已译、不进入成功缓存。最终完整结果仍须经过既有严格校验；失败、停止和来源失效撤下未确认部分，其他已确认分块保留。Antigravity CLI 不承诺 token 级输出。
5. 长段落分块使用切块处紧邻的同段前后文，各最多400字符；首尾保留外部邻段。原有每批四项/4000源字符、12000源文加上下文上限不变。
6. 本页提示词要求完整、自然、忠实的译文而非摘要，保留否定、条件、数值、术语与段落。译文缓存策略版本升为2；旧选段/本页策略结果不再命中，词档案和阅读记录不迁移。
7. 确认本页翻译后暂停该页的自动词注、领域识别与非显式解构，清理失效排队任务；自动 API 请求（含领域识别及自动解构的路由判定）仅在所有共享使用者都失效时中止，显式请求及其他页面的有效使用者不受影响。原请求结算后释放槽位，不提高并发。授权串行写入完成后再复核使用者，避免 guard 重入死锁；主动中止按 cancelled 诊断，不伪报服务失败或切换备用服务。订阅连接器的在途推理仍按原协议等待结束，不能假装已经取消。 取消不写判定失败路由缓存；已报告或估算的用量仍计入请求汇总与预算，不计服务错误或成功答案。provider NOT_READY 保持失败，不能用取消分类隐藏真实未就绪故障。 领域识别入场及共享使用者复核相同授权，取消不缓存领域结果；显式分类与设置页测试保留。 取消边界沿用诊断对导航过期 guard 的分类。迟到有效显式解构加入已取消共享推理时，最多一次重新采用有效推理，保留既选路由与已得结果，不重试真实服务错误。

## 结果

### 正面影响

受控浏览器对照可见首字提前，慢批次不再阻塞第三批；不提高并发，主动译文的批次边界不变。确认本页翻译后，失效自动 API 推理不再占用首批译文所需的槽位。

### 代价与风险

预览可能被最终译文替换或因失败撤下，不保证内容正确。冷缓存可能重新计费。服务模型与网络仍决定实际耗时；不支持增量的服务只能等待最终结果。提示词约束与局部上下文不等于文章级术语一致性或模型质量保证。中止 API 传输不能保证服务商未计费；已发送给订阅连接器的自动推理仍可能占用槽位。

## 实施与验证

见 [开发记录](../records/2026-10-06-page-translation-performance.md)：实际浏览器受控 SSE 对照、明暗主题、停止/失败/禁用清理、旧缓存隔离、公开文本六次模型对照，以及完整项目检查。新增回归覆盖滚动补位、较低并发上限、代次交错、隐藏/重扫、伪造进度与同段已确认分块保留。
