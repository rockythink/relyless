# ADR 0002：专注阅读使用单一临时正文表面

- 状态：accepted
- 日期：2026-09-23
- 参与讨论：rockythink，见 [Issue #23](https://github.com/rockythink/relyless/issues/23)
- 取代：无
- 被取代：无

## 背景

用户希望主动排除网页布局干扰，同时保持原文、原页交互和已有英文辅助边界。正文识别可能失败；模型不可用于弥补不可靠的提取。

## 备选方案

iframe 或 Shadow DOM 会切断当前同文档 Range、Selection 与 CSS Highlights 路径。直接改写原网页会破坏输入、事件监听与位置恢复。远程提取增加权限、正文传输和成本。

## 决策

使用用户主动开启的同文档 light DOM 手动 popover；本地结构证据识别正文，不可靠则拒绝。按白名单重建一次原文快照，不搬动宿主节点；仅内存持有快照及源节点映射。辅助只在当前表面运行，原页与阅读视图切换时淘汰旧请求和注释。阅读排版选择只在本页会话有效，不新增权限、远程提取或文章持久化。英文自动辅助原有语言和 on-demand 闸门保持不变；视图内查词键单击是明确求助，即使未开启本页自动辅助也不触发被动工作。原页双语在切换时停止新请求并保留已译内容，退出恢复原页停止态，读者可继续或清除。视图顶部整页翻译仍须逐次确认用量/预算，复用现有按阅读位置翻译通路，但结果与原页会话隔离；进入视图本身无模型请求。

## 结果与风险

宿主脚本改写源页面后快照可能过时；退出再进入可刷新。未加载图片、嵌入媒体和不可靠正文给出原页查看或拒绝；图片可能再次请求资源，不能声称完全离线。已发送的翻译请求可能计费，停止或退出不能撤回。退出必须恢复本模块更改的 inert、overflow、焦点和滚动，不覆盖宿主后续写入。

## 验证

英中正文、恶意属性和歧义页测试；真实 Chrome popup、焦点、滚动、on-demand 和辅助弹层场景；`npm run check`。
